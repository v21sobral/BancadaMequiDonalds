# Bancada MequiDonalds — Frontend

Aplicação React + Vite.

## Desenvolvimento

Crie `Frontend/.env`:

```env
VITE_API_URL=http://localhost:3000
```

Depois:

```bash
npm install
npm run dev
```

## Vercel

Defina no projeto do frontend:

```env
VITE_API_URL=https://SEU-BACKEND.vercel.app
```

O endereço deve apontar para a API publicada, sem barra `/` no final.
